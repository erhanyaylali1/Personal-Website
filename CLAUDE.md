## Context Navigation

When you need to understand the codebase, docs, or any files in this project:

1. ALWAYS query the knowledge graph via terminal first: run `graphify query "your question"` in the shell.
2. Only read raw files if I explicitly say "read the file" or "look at the raw file"
3. Use `graphify-out/GRAPH_REPORT.md` as your navigation entrypoint for browsing structure.
